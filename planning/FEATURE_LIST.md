# Feature Roadmap

## Implemented

- Buyer, seller, and admin roles
- JWT authentication and bcrypt password hashing
- Product categories, listing, search, and filtering
- Product details and cart
- Checkout and transactional stock reduction
- Buyer order history
- Seller dashboard and product management
- Local image upload support
- Seller order status updates
- Admin dashboard
- User enable/disable controls
- Local JSON persistence with seeded demo data
- Environment validation and health endpoint
- Repository verification script and GitHub Actions CI

## High-value next features

- PostgreSQL persistence and migrations
- Paystack or Flutterwave payments
- Delivery/rider workflow
- Seller approval workflow
- Product reviews and ratings
- Cloudinary/S3-compatible image storage
- Password reset and email verification
- Rate limiting and structured request validation
- Audit logs
- Wishlist and coupon codes
- PDF invoices
- Marketplace analytics
