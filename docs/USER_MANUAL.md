# User Manual

## Buyer Guide

### Register as a Buyer

1. Open the website.
2. Click Register.
3. Choose Buyer.
4. Enter your name, email, password, phone, town, and address.
5. Click Create Account.

### Browse Products

1. Click Products.
2. Use the search bar to find items.
3. Use the category filter to narrow results.
4. Click a product to view details.

### Add to Cart

1. Open a product.
2. Choose quantity.
3. Click Add to Cart.

### Place an Order

1. Open Cart.
2. Click Proceed to Checkout.
3. Enter delivery information.
4. Select delivery or pickup.
5. Select payment method.
6. Click Place Order.

### View Orders

1. Login as a buyer.
2. Click My Orders.
3. View order status and order items.

## Seller Guide

### Register as a Seller

1. Click Register.
2. Choose Seller.
3. Enter personal details.
4. Enter shop name and shop description.
5. Click Create Account.

### Add Product

1. Login as seller.
2. Go to Seller Dashboard.
3. Fill the Add New Product form.
4. Enter product name, description, price, stock, category, and image URL.
5. Click Add Product.

### Manage Orders

1. Go to Seller Dashboard.
2. Scroll to Recent Customer Orders.
3. Use the status dropdown to update order progress.

### Monitor Marketplace

1. Go to Admin Dashboard.
2. View user count, seller count, products, orders, and gross sales.
3. View users and recent orders.
4. Disable or enable user accounts when needed.
