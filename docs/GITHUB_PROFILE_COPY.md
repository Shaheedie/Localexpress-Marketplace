## Pinned-project summary

LocalExpress is a full-stack multi-vendor marketplace demonstrating role-based buyer, seller and administrator workflows. It includes JWT authentication, seller inventory management, product search, cart and checkout, order processing, local image upload, responsive UI and documented REST APIs.
