# GitHub Publication Checklist

Before making the repository public:

- [ ] Run `npm run check`.
- [ ] Run `npm run build`.
- [ ] Confirm `.env` files are not tracked.
- [ ] Confirm `backend/src/database/localexpress-data.json` is not tracked.
- [ ] Confirm uploaded local images are not tracked.
- [ ] Review demo account credentials and ensure they are used only for seeded local data.
- [ ] Add 3–5 screenshots or a short demo GIF to the README when available.
- [ ] Add the deployed frontend/API links if a hosted demo exists.
- [ ] Choose an open-source license only if you intend to permit reuse.
- [ ] Create a release tag after the first public version is verified.
