# Project Proposal

## Title

Design and Implementation of a Local Town-Based Multi-Vendor E-Commerce Marketplace System

## Background of the Study

Local businesses are important to the economy of many towns because they provide daily goods and services to people within the community. However, many small sellers still rely mainly on physical shops, phone calls, WhatsApp status, Instagram pages, or word-of-mouth to reach customers. These methods are useful but not always organized. Customers may not easily know what products are available, sellers may find it difficult to manage orders, and buyers may not have a central platform for comparing local products.

A local e-commerce marketplace provides a better approach by creating one platform where sellers can upload products and buyers can place orders. Unlike large national or international e-commerce platforms, this system focuses on local town trading, faster physical exchange, and easier communication between nearby buyers and sellers.

## Statement of the Problem

Many local sellers do not have a dedicated online platform for displaying their products and receiving customer orders. Existing informal methods such as social media posts and messaging groups can become disorganized because product details, customer information, stock records, and order updates are not stored in one system. Buyers also find it difficult to search products from different local sellers in one place. This creates a need for a local town-based marketplace that supports product listing, cart, checkout, order management, and admin monitoring.

## Aim

The aim of this project is to design and implement a local town-based multi-vendor e-commerce marketplace system that enables sellers to advertise products and allows buyers to place orders conveniently.

## Objectives

1. To develop a registration and login system for buyers, sellers, and administrators.
2. To design a product management module for sellers.
3. To implement product browsing, search, cart, and checkout features for buyers.
4. To create an order management system for buyers and sellers.
5. To provide an admin dashboard for monitoring marketplace activities.

## Significance of the Project

The project is significant because it helps local sellers reach more customers, helps buyers discover products easily, and provides a more organized way of managing local online orders. It can also support small businesses by giving them a simple digital presence.

## Scope

The project covers user authentication, seller shop setup, product listing, product search, cart, checkout, order placement, seller dashboard, buyer order history, and admin dashboard. The project does not currently include live online payment, delivery rider tracking, or advanced fraud detection.

## Methodology

The system is developed using a client-server approach. The frontend is built with React, the backend is built with Node.js and Express.js, and a local JSON file database is used for simple development. The system uses JWT for authentication and bcryptjs for password hashing.

## Expected Outcome

The expected outcome is a functional web-based local e-commerce marketplace where buyers can place orders and sellers can manage products and orders.
